ДЗ3

Открой Домашняя_NLP.ipynb. Исходные инструкции, результаты, анализ ошибок и выводы сохранены в ячейках. Ответы на контрольные вопросы находятся в answers.md.

В results/metrics_summary.csv находится таблица метрик. В results/predictions.csv находятся предсказания с ID, названием модели и выборкой. Поле source_file позволяет сопоставить их с исходным экспериментом. Настройки, порог ручной проверки, матрицы ошибок, оценки по классам и остальные таблицы находятся в results/details.json и показаны в ноутбуке.

results/generator_validation.jsonl содержит 60 исходных ответов, по 30 для zero-shot и few-shot. results/generator_test.jsonl содержит 150 ответов. results/generator_injection.jsonl содержит 12 ответов отдельной проверки. Поле raw_response сохранено дословно.

Материалы пункта 4 пока не приложены. Логи TensorBoard, результаты повторной загрузки ruBERT и таблица измерений времени будут добавлены отдельно.

Код обучения, генерации и оценки находится в experiment.py. common.py содержит функции чтения и оценки. prepare_data.py и split_ids.json взяты из задания и нужны для исходной ячейки подготовки данных.

Для запуска распакуй весь архив, установи requirements.txt и открой ноутбук с интерпретатором этого окружения. Начальные ячейки установки зависимостей и подготовки данных сохранены из задания. Для подготовки данных нужен интернет.

RUN_EXPERIMENTS = False показывает сохранённые результаты. Для нового обучения используй отдельную копию без results и logs, затем задай RUN_EXPERIMENTS = True или выполни python experiment.py all. Новые рабочие файлы будут созданы автоматически. Полное повторение скачивает фиксированные версии моделей. Веса и API-ключи в комплект не включены.

TensorBoard запускается командой python -m tensorboard.main --logdir logs/rubert --port 6006.

Данные RuReviews получены из репозитория https://github.com/sismetanin/rureviews и распространяются по Apache 2.0. Тональность получена из оценок покупателей. Модели cointegrated/rubert-tiny2 и Qwen/Qwen2.5-0.5B-Instruct, точные версии записаны в results/details.json.
